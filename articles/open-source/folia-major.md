在本地与流媒体音乐播放器领域，绝大多数工具在歌词展示上依然停留在传统的逐行滚动甚至静态文本阶段。而开源项目 **folia-major**（GitHub: `chthollyphile/folia-major`）另辟蹊径，将视觉重点放在了极具冲击力的**歌词动画与音频可视化动效**上。

它不仅支持本地音乐目录索引，还打通了 Navidrome 等流媒体自建服务及多平台在线源，同时基于现代 Web 技术与 Electron 构建出媲美专业视效软件的动态歌词体验。

---

## 核心亮点与技术实现

### 1. 极致打磨的逐字歌词渲染与动效引擎
folia-major 的核心竞争力在于对歌词动效的细腻刻画：
- **逐字动画（Tilt / Sentence Layout）**：针对具备精确逐字时轴的歌词（如 QQ 音乐逐字源），采用细粒度分词与平滑插值算法，文字逐个随节拍翻转或浮现，告别生硬的卡拉 OK 式填充。
- **“镜台” 3D 点云与粒子系统**：内置名为“镜台”的 3D 歌词点云模式，将文字分解为空间粒子，随音频振幅产生波浪与扩散效果。
- **4K 120 FPS 优化目标**：动效层基于 Canvas / WebGL 渲染，整体架构优先保障高帧率与低延迟响应。

### 2. 多源统一与自建流媒体生态
播放器摆脱了单一平台的限制：
- **自建云端接入**：原生兼容 **Navidrome** 等 Subsonic 协议自建音乐库，随时同步云端收藏。
- **本地高效扫描**：针对本地数百首曲目实现秒级快照对比（Snapshot Diff）与增量索引，元数据在后台水合加载（Hydration）。
- **智能歌词源对齐**：支持跨源检索并自动优先匹配带有逐字精度的歌词数据源。

### 3. 系统级深度集成与主播场景支持
- **OBS 直播推流**：Web 版本支持一键生成 OBS 静态串流与透明背景歌词链接，透传外观与样式参数，为主播提供即开即用的推流歌词插件。
- **原生外观质感**：Windows 端深度集成 Acrylic / Mica 云母透明特效，macOS 与 Linux 提供原生包构建，兼顾跨平台统一感。

在众多音乐播放器趋于同质化、工具化的今天，folia-major 选择以“视觉表现力”为切入点，把歌词展示从“附属功能”提升为了“视觉主角”。对于追求桌面美学、直播推流以及喜欢高品质动态歌词的极客与音乐爱好者来说，是一个值得关注与尝试的优秀开源实践。
